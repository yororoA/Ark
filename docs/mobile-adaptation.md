# 手机端适配

当前分支：`feat/mobile-adaptation`。

覆盖档案、青笺、P3R、月之暗面四套主题，保留各自的颜色、装饰与动效。

## 改动

- 导航：手机菜单、横屏菜单、触屏点击区域、菜单滚动与焦点返回；外观设置与页脚窄屏布局。
- 聊天：按可视视口调整高度，适配键盘缩小和上移可视区域；正常与放大模式都保留输入区，短屏布局按容器高度切换；横向会话列表、附件滚动、消息宽度；虚拟列表测量与用户滚动分别处理。
- 编辑与阅读：手机输入字号 16px、宽代码和表格独立滚动、长标题和标签换行。
- 媒体：按原图比例完整显示，双指连续缩放、单指平移、缩放与位移一起复位，横屏预览保留图片空间，视频内联播放。
- 登录：账号弹窗随可视区域缩小和上移，短屏账号列表、注册字段与操作区独立滚动；弹窗焦点、Esc、嵌套删除确认；触屏声明使用原生滚动。
- 安全区：顶部导航高度包含顶部安全区，弹窗与页面操作区预留底部安全区。
- 补充组件：四主题菜单断点统一到 1100px；通用弹窗和删除确认使用可视视口；长文件名、错误信息、回复对象与媒体描述保留操作空间。
- 编辑细节：横竖屏切换自动重算文本框高度，计入边框；自动重试期间保留错误恢复按钮；留言分页后发送会刷新第一页。
- 实验室与加载：内嵌播放器窄屏单列、16px 输入字号和 44px 控件；加载文案在短屏换行，支持减少动态效果；桌宠开关 44px，输入期间避开编辑区域。
- 反馈修正：手机登录表单在可视区域内居中；P3R 菜单把原生弹窗、展开裁剪和内容滚动分层，所有入口在 420ms 展开周期内显示完整；档案与青笺采用独立全屏菜单，各自包含品牌、目录、关闭按钮与登录入口；桌宠在常见手机上由 128px 缩为 64px，320px 窄屏继续按比例缩小。

## 运行

需要 Node.js 24 与 Playwright Chromium。测试只能针对隔离的内存后端运行，避免写入真实数据。

```sh
npx playwright install chromium
ARK_VERIFY_PORT=10400 npm run verify:blog:preview
```

等待输出 `19/19 integration groups passed` 后，在另一个终端运行：

```sh
TEST_BASE_URL=http://127.0.0.1:10400 npm run verify:mobile
```

此命令依次运行 88 项页面回归、76 项组件回归和 23 项反馈回归。仅复测组件时使用 `npm run verify:mobile:components`，仅复测本轮反馈时使用 `npm run verify:mobile:feedback`。

如果已有 Chromium，可设置 `PLAYWRIGHT_EXECUTABLE_PATH`。`MOBILE_SCREENSHOT_DIR` 可指定已有目录保存截图。

接口验证与浏览器写入测试应依次运行；同时运行会干扰内存后端的调用数量断言。每次变更后使用一个新端口创建预览，因为预览使用源码快照。不要使用浏览器保留端口，例如 10080。

生产质量门禁：

```sh
npm run check:quality
```

该命令包含 lint、类型检查、生产构建、资源预算与 19 组接口契约验证。
