# P3R 主题：视频参考与实现记录

分支：`feat/p3r-theme`。基于已合入青笺主题的 `main`（`7e15720`）。

目标：在现有个人博客中增加一套参考《Persona 3 Reload》的完整主题，覆盖导航结构、
页面编排、颜色、字体、过渡、悬停、点击及登录反馈。主题入口使用「P3R」，
与档案、青笺并列，支持明暗模式、系统偏好、中英日德四种语言和移动端。

## 设计提炼

### 结构与文字

- 导航是有明确选中项的倾斜文字菜单，配合大面积留白与裁切的大字，不是同尺寸卡片。
- 深蓝信息区、白色斜带和青色背景具有不同职责；宽标题区、窄目录与正文区形成明显层级。
- 英文字体窄、粗、斜，字号悬殊，常用大写与紧字距；中文内容采用清楚的无衬线字体。
- 列表条目紧凑，悬停/选中时突出当前一行；关联信息位于另一个区域，避免每一项都包成厚卡片。
- 月历、存档列表、邮件、配置各有编排方式；新主题需要覆盖文章、片刻、归档、映像、
  阅读、关于、实验室、聊天、登录与所有共享浮层。

### 配色与层次

- 主场景：高饱和钴蓝、深海军蓝、亮青、纸白；洋红只用于指示和反馈。
- 强调元素使用白色片层、青色字与细洋红边缘；正文阅读区域保持稳定背景和足够对比度。
- 浅色模式保留蓝色场景及白色阅读纸面；深色模式采用深海军蓝内容面板。
- 背景使用水面波形、圆弧、月亮、窗格与稀疏几何碎片；作者身份与真实内容继续作为主体。

### 动作

- 菜单选中：切片先响应，再以短距离位移安定；白条和洋红边缘强调当前项。
- 菜单开启/页面进入：场景、标题、菜单行分层出现，列表使用短交错时序。
- 弹窗：参考邮件蓝色斜面先进入、再露出内容的次序；正文和输入框保持水平。
- 跨页导航：从真实落点扩张蓝色圆面，薄青白边缘先行，铺满后从同圆心揭开。
- 登录：银白石子从顶部加速下坠，统一水体快速放大，泡沫和气泡上散；路由就绪后向上退水。
- 使用无回弹曲线；短反馈约 120–180ms，面板约 260–420ms。此为网页交互目标，
  不声称是原视频精确时长。减少动态效果时保留颜色、边缘和状态变化，停止位移与循环。

## 实现约束与入口

- `src/lib/appearance.ts`：增加 `p3r` 标识，同时更新持久化解析及首屏 bootstrap 白名单。
- `src/styles/appearance.scss`：集中维护 P3R 明暗语义颜色。
- `src/components/appearance/theme-picker.*`：第三个预览、四语言名称与说明、窄屏布局。
- `src/components/blog/_p3r-ui.scss`：全站布局与控件样式，编译进入既有 CSS Module；
  主题选择不重新挂载文章、聊天输入或其他业务内容。
- 独立场景和菜单组件：有实际导航目标，支持键盘、焦点返回、关闭及触屏。
- 只有引起 `pathname` 变化的站内 Link 使用全屏圆面，并通过 `onNavigate` 在覆盖后交接；
  同页锚点、查询筛选、弹窗、主题切换和其他按钮不触发该效果。
  保留预取、replace、scroll 与 transitionTypes。新标签、下载、站外和同页链接保持原行为；不添加默认音效。
- 登录与账号弹窗沿用现有认证契约；失败、取消、跳过、慢路由、减少动态效果都需要可用。
- 设计声明补充 ATLUS / SEGA 的参考归属和上述 B 站来源。
- 更新 `.uicraft.md` 的主题说明，同时同步青笺名称。

## 实现

- 第三主题标识、首屏持久化、明暗颜色和四语言主题说明。

  两侧气泡散开，之后留下水下场景；约 3.05 秒也有蓝色圆形菜单切换。

- 纯代码演绎：棱角石替代原片人物；保留加速下坠、宽顶尖底水痕、泡沫拖尾和气泡。

- 点击转场采用「铺色 → 就绪交接 → 圆形揭示」；半径计算到最远的屏幕角并留出边缘余量，
  快速连续操作清理旧动画，保留新标签页、下载和键盘操作的原有行为。
- 登录继续复用既有认证、取消、失败、跳过、慢路由和目标就绪契约；
  减少动态效果及渲染不可用时使用静态遮场。

标注时间为采样位置，误差在相邻原视频帧内。

### 第二轮代码与时序（截至 439b851）

- 圆面使用 Canvas 2D：380ms 铺色、至少 60ms 完整覆盖、360ms 同圆心开孔。
  导航通过 Next 16 的 `onNavigate` 接入，原生修饰键/下载/站外链接不进入延迟交接。
  以已提交的 pathname 解除遮场，支持目标重定向；12 秒兜底或 Esc 可移除卡住的视觉层。
  非跨页操作不请求圆面；登录开始时清理圆面，避免两段效果重叠。
- 圆面使用不获取焦点的 manual popover 覆盖原生 dialog；无 popover API 时使用 fixed 层，
  此时无法保证高于原生模态 dialog。Canvas 不可用时直接使用原生链接。
- 登录使用约 1.75 秒落石入水、约 0.76 秒分水揭示。石子折面、非对称泡沫条带、
  拉长的碎泡与离散气泡全部由独立几何和确定性参数绘制，没有视频帧或贴图依赖。
  初始画布透明，坠物与水痕覆盖原登录背景；完整不透明后才允许跳转。
- 入水主体由五股错时水柱组成，各自具有不同宽度、弯曲、长度和落点；
  白青内芯采用断续段，泡沫在水柱内部及下半部斜向爆开，不再形成封闭深蓝漏斗。
  爆裂阶段保持半透明，仅在最后约 100ms 合并为路由交接所需的不透明遮场。
- 帧状态放在 RAF / DOM ref 中，不逐帧触发 React 渲染；画布像素比上限 1.5。
  登录静态等待时停止 RAF，页面隐藏时停止绘制；窗口改变后按新尺寸重绘。
  减少动态效果、运行中切换偏好、Canvas 获取失败均能完成登录握手。

## 无字版参考与形态校正

主参考：[Cuthorns《p3re菜单动画无字纯享版》](https://www.bilibili.com/video/BV15V4y117GZ/)。
读取 P1（179.489 秒、852×480）；投稿说明称取自 `p3re.jp` 官网，P1 带 intro，P2 为循环。
已采样 P1 全程概览与开头 3.2 秒的 0.1 秒间隔图版，原片与图版仅存于
`.git/ark-research/p3r/clean-menu*`，不作为站点素材。

- 约 0–0.9 秒是白底；约 1.0–1.2 秒水体从顶部冲入，上宽下尖并快速放大，
  内部存在长短不同的白青泡沫条，两侧是团块和带孔碎泡。
- 约 1.3–1.6 秒泡沫逐渐向上散去，留下顶部亮青、底部深蓝的水下渐变，
  水面碎光集中在上方；此后为人物和水面缓慢运动的循环。
- 无字画面澄清了此前的误判：长条属于同一个水体内部的泡沫，
  不应实现为五股 / 三股独立瀑布。旧实现保留于 `439b851`。
- 新 `p3r-water-renderer.ts` 集中管理水体轮廓、泡沫条、带孔泡沫团、偏心气泡、
  水面碎光与逐帧绘制。React 组件只管理生命周期、尺寸和减少动态效果降级。
- 进入阶段以一次浅白过渡衬托水体轮廓，随后蓝色水体取代背景；
  窄屏使用同一比例的场景居中裁切，避免按屏幕宽高拉伸后变成细针。
- 保留约 1.75 秒入水与 0.76 秒揭示的网页时序，原角色仍以原创石子替代。
  最后阶段连续过渡至相同的不透明等待帧，确认目标路由提交后才揭开。
  向上退水是网站为页面交接设计的退场；该视频本身未展示退场镜头。
- 本轮仅修改登录水效；页面圆形转场仍只用于跨 `pathname` 导航。
