## 上一版的偏差

- 圆角按钮、弧形卡片、圆润聊天气泡和拱形身份面板来自泛化的“安静书页”联想，缺乏对应帧依据。
- 居中标题下重复添加一个水纹图标，只延续了局部符号，没有延续原片的排版和空间关系。
- 原片中的白色矩形条带、青色切片、细边框、密集小字与超大细宋体之间的尺度差，在内容页中基本消失。
- 动画只剩慢速浮动，缺少原片“遮挡—揭示”和前后平面错位的关系。

## 实施方向

1. **共享构图**：青笺内容页使用薄矩形画框、浅青场景层和偏置文字区；导航、筛选、按钮改为平直标签条。保留首页已被认可的伞幕主体。
2. **章节标题**：中文 / 日文短标题采用大号细宋体竖排，英文使用旁置横向标题条；八角片、竖向切片和细线框承担背景构图。长篇文章标题保持横排和舒适行宽。
3. **列表与归档**：封面改为矩形取景框与少量切片；日期和类别成为白色 / 深色小标签；日期控件与真实内容日历沿用月历式细线网格。
4. **阅读与聊天**：阅读页以细线元信息栏和错层页边建立识别；聊天使用直角纸条、淡青侧栏和双层方片标记。布局变化不能破坏回复定位、草稿、放大模式或媒体预览。
5. **登录与弹层**：使用浅白窄栏、青色平面和片层构图，替换拱顶、胶囊与大圆角；统一日期、选择器、主题面板和账号面板。
6. **动效**：采用短程片层揭示、偏移背景和细线展开，保持文字稳定；不复制原片的频闪、快速闪白和强折射。所有空间动画支持减少动态效果设置。

实现和验证结束后，在 `rain-theme.md` 中记录最终覆盖范围；以本文件的时间点逐项对照视觉结果，避免只检验“是否换色”。
