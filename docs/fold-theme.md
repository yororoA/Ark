# 折境 / FOLD

第六套外观，主题标识 `fold`，在 `/theme` 选择。以硬边几何插画、限色平涂和叙事海报为起点：悬置巨构与微小行旅者形成尺度反差，纸白负空间直接参与造型。所有画面使用代码绘制，没有引入参考图作为网站素材。

## 构图

- 原创 SVG「悬置」以截断于画框外的巨大悬臂、偏心的行旅者和汇聚地面组成；「通行」以不对称墙面、退远的横梁与红门构成纵深。
- 首页标题采用错位分行；手机上重新编成横向标题和整幅画面。鼠标移动时，不同深度的建筑层产生轻微、缓动的相对位移。
- 深色模式使用炭黑纸底、银蓝折面和暖朱红信号；图像色块与可读文字分别配色。首页、菜单、登录、转场和静态主题封面同步切换，跟随系统时也会实时更新。主题封面使用同一绘图组件的静态版本。支持四种现有语言。
- 导航和页脚使用网站共用 Logo；文章、片刻、编辑器与通信的数据及业务行为沿用网站现有实现。

## 动作设计

- 首页由地面、远景、两侧悬臂、中央结构和微小行旅者分次建立，约 2.4 秒落定，不循环漂浮。场景切换先以两片斜面覆盖，再换画并展开。
- 内容滚动时，标题沿切口展开，封面由侧面揭示，正文分组进入。文章悬停与键盘聚焦联动封面裁切、文字、日期、箭头和底部红线。
- 菜单为大字裁切 INDEX 海报，选中目录联动编号与几何折板。开合有相反的切口方向；保持方向键、Home/End、Tab 循环、Escape、焦点归还和短屏滚动。
- 页面转场使用四片不等宽的斜向折板：约 440ms 合拢，完全覆盖后导航，实际内容就绪后用约 700ms 分层揭开。旧页和新页不直接交叉闪现；菜单在覆盖下退出。来源路径、查询参数和页内位置保留。
- 登录是独立全屏镜头：纸面红折痕、纸片打开、穿行多层通道、接近红门、纸叶合拢。完整前段约 4.6 秒，认证成功后在遮挡下导航，新页真实内容准备好后约 850ms 揭开。待认证时停留，不虚构进度；支持取消、错误返回、跳过及慢导航恢复入口。
- 全站转场覆盖时暂停首页及内容标题入场，揭幕时才继续。减少动态模式直接呈现构图、取消视差与位移动效，并缩短登录过渡。

## 实现入口

- `src/lib/appearance.ts`、`src/lib/fold.ts`：主题注册、偏好恢复、名称和描述。
- `src/styles/appearance.scss`：浅色、深色与固定印刷色板。
- `src/components/appearance/fold-art.*`：双构图及分层入场。
- `src/components/blog/fold-home.*`：海报首页、画面切换、视差和滚动揭示。
- `src/components/blog/fold-menu.*`、`_fold-ui.scss`：目录与全站内容样式。
- `src/components/appearance/fold-effects.*`、`fold-transition.ts`：页面转场与导航交接。
- `src/app/login/_fold-login.scss`、`src/components/appearance/fold-connection*`：登录排版、独立绘图和镜头时序。
- `src/components/appearance/rain-connection-boundary.tsx`：登录跨路由承接，仅为 Fold 增加实际内容就绪判断。

## 验证范围

在隔离接口预览中检查桌面、390px、320px和短屏，浅色/深色/跟随系统，四种语言、主题保存、首页双构图、视差、滚动揭示与动态偏好切换。检查菜单键盘/焦点/关闭/来源恢复，普通及慢页面切换，以及登录正常、等待、取消、失败、跳过和减少动态。没有使用真实账户执行写入。
