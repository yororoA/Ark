# 月之暗面 / Dark Side

内部标识 `prism`，分支 `feat/dark-side-theme`。新增第四套主题；原有 `ark.design.v1`、
`ark.theme` 和四语言偏好保持兼容。视觉主题与明暗模式分别选择。

## 依据与方向

参考 Pink Floyd《The Dark Side of the Moon》（1973）的棱镜封面。
[Sony Music / Pink Floyd 官方资料](https://www.pinkfloyd.jp/artist/PinkFloyd/info/548891)
记载封面的构思来自 Hipgnosis / Storm Thorgerson，绘制者为 George Hardie。
本实现以 SVG / CSS / Canvas 绘制几何，不使用封面位图、歌词或专辑音频。

核心是“光路、唱片封套、内页小字与留白”。光谱承担方向、选择和交接，正文保持清晰。
黑胶黑 `#0b0d0e` 与冷灰纸 `#e7eae8` 是明暗两套底色；亮暗之间不改变用户的内容或草稿。

## 第二次构图调整

用户指出首版像“档案和 P3R 融合”，并提供首页、菜单及首页下半部截图。
据此放弃大字左右分栏、重复棱镜横幅、宋体目录与旧日历格的组合：

- **页头与页脚**：与其它主题共用品牌 Logo；博客与登录页使用 `ArchiveLogo`，页脚使用通用 Logo 与签名组合。
  保留月之暗面的导航选中样式与页面配色。
- **首页**：从屏幕左侧入射，棱镜折射到屏幕右边缘；大小写拉开字距的小标题与署名让主体图形成为焦点。
  浅色首页、页头、正文使用同一套冷灰纸色，避免暖白页头接黑色海报的断层。
- **首页内容**：独立的 A/B 分区；文章为真实封面与说明并列的唱片封套，片刻按日期刻度分布。
  活跃日期为可访问的细刻度链接，链接仍指向真实日期筛选。仓库与提交数继续使用现有 API。
  未提供封面时使用几何刻纹，数据为空、加载失败或尚在加载时复用现有 `State`。
- **导航**：桌面入口分布在中央棱镜周围，与真实可点击区域共用端点坐标。
  悬停与键盘焦点点亮对应光线；窄屏变为两列触控入口。取消巨型英文菜单标题。
- **章节**：开放的标题空间、圆形编号、掠过月相细线的光谱，取消黑色棱镜横幅。
- **文章**：方形唱片封套排列，日期成为小字信息；片刻沿垂直时间线展开。
  正文、元信息、归档、映像、关于、友链、留言、实验室、社区约定、公告、错误页使用同一无衬线系统。
- **表单与通信**：输入边线、圆形头像、左右消息识别线、编辑器与上传面板共用语义颜色。
  不更换编辑器、上传、会话、列表返回位置或媒体缩放逻辑。
- **弹层与登录**：账号管理、声明、确认弹窗、选择浮层、日期、媒体预览和主题选择器覆盖新主题。
  登录页收敛英文大字；第二轮接入仍使用棱镜，第三轮已替换为月蚀。

## 第三次打磨：实体封套、导航状态与月蚀

针对“文章封套一般”“tab 一般”“登录动画和首页一样”以及增加闪烁星点的反馈：

- 首页和文章列表复用 `PrismRecord`：纸套侧脊、真实封面上的小字排印、唱片刻纹与中心标，
  唱片部分露在纸套外。悬停 / 键盘聚焦时唱片平滑抽出、微转，纸套轻微倾斜；触屏静态露出唱片，
  不依赖悬停才能辨认。无封面时用原创的光学封套。旧平面实现保留在 `e365015`。
- 页头导航、分类筛选和账号注册/登录使用分段式 tab，选中项有完整底色、光谱细线和明确边界；
  账号切换按钮提供 `aria-pressed`。
- 放射导航收紧间距，中心增加双轨道刻度，选中 / 聚焦入口的编号、边框、连线与中心标题联动。
  当前页面的光路在鼠标移开后继续显示；窄屏保持两列入口。
- 页面、菜单、登录背景增加 112 个固定分布的 SVG 星点，以不同周期（约 4.8–10.5 秒）变化透明度。
  不移动正文，不接收指针事件，不使用常驻 RAF；文段中央减淡，隐藏标签页时暂停，
  减少动态效果时保留静止星空。
- 登录使用独立 Canvas 月蚀：暗月横过明亮圆面、边缘暖光收束、全食与放射状日冕等待，
  随后圆形开口从月面中心扩张至屏幕边缘。星空和月蚀图形由代码绘制，不复用首页 `PrismScene`。
  登录错误、取消、跳过、迟到响应和慢路由仍由原连接边界处理。

## 动作规则

1. 首屏依次显现棱镜、入射光、六色出射光；单次边缘亮线描过棱镜。
   精确鼠标小幅改变出射光角度，触屏和减少动态效果下关闭。
2. 首页内容进入视口后一次性显现；离开视口不重播，键盘焦点可直接显现尚未进入的内容。
   无 JavaScript / IntersectionObserver 时内容默认可见。
3. 全屏导航通过光缝展开，关闭从当前裁切位置收拢。
   原生 dialog 负责焦点约束，退出后恢复打开按钮；支持方向键、Home / End、Escape。
4. 只有改变 pathname 的站内 Link 使用光谱斜面转场：320ms 遮住、至少 70ms 等待、
   390ms 揭开。全遮后才执行调用方 `onNavigate` 及路由操作，加载骨架最多额外遮住 300ms。
   8 秒未提交时使用原生导航兜底。查询、锚点、修饰键、下载与外链保留原语义。
5. Escape、页面隐藏或运行时减少动态效果会跳过转场视觉并保留导航；
   尚未交接时再次点击替换目标。取消导航则揭开原页面。
6. 登录的月蚀入场约 2100ms，身份验证成功且全遮后跳转，目标提交后约 850ms 圆形揭开。
   pending 可返回，错误可重试，success 可跳过；慢路由提供直接访问与返回。
   动态模块加载时只显示透明交互遮层与屏幕阅读器状态；Canvas 不可用时静态交接。
7. `html[data-prism-wipe="covered"]` 暂停目标页入场，揭开后播放。
   减少动态效果时禁用入场、视差、菜单裁切、光谱转场与登录动画。
