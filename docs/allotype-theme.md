# 异相 / ALLOTYPE

以用户提供的五组哈希为视觉种子，构成可交互的实验海报：姜黄纸面、酒紫油墨、荧红大字、酸绿印版，配合错位标题与衬线斜体。首页以“保持异相”为题，将图形作为独立印版；每次选择同时改变图形、印版底色、编号、名称及字节条纹。深色模式使用近黑酒紫底与暖黄色正文。

## 数值与视觉的关系

| 种子 | 前六位色值 | 视觉用途 |
| --- | --- | --- |
| MD5 | `#919119` | 橄榄色标 |
| SHA-1 | `#c6dc4c` | 酸绿贴纸 |
| SHA-256 | `#e7d47b` | 姜黄纸面、深色油墨 |
| SHA3-256 | `#623b49` | 酒紫印刷色、导航底色 |
| BLAKE2b | `#ff1346` | 荧红套印线、展示字 |

完整数值保存在 `src/lib/allotype.ts`。`allotypeMarks` 将每个字节混入确定性种子，五种算法各自生成一套原生 SVG 图形，服务端与客户端的输出一致：

| 哈希 | 形态 | 绘制方式 |
| --- | --- | --- |
| MD5 | 干涉 | 经纬织线构成倾斜环面，荧红曲线错色套印 |
| SHA-1 | 轨迹 | 多组偏转轨道围绕留白圆心交织 |
| SHA-256 | 点阵 | 种子控制起伏与点的大小，形成半调地形 |
| SHA3-256 | 折叠 | 连续曲线沿扭带翻转，以异色表现边缘 |
| BLAKE2b | 日蚀 | 长短不同的尖锐射线与内环刻度围绕空心排列 |

每组最多 225 条 SVG 路径，不使用外部图片、滤镜或运行时随机数。底部的条纹直接按哈希字节绘制。这里的“数字指纹”是艺术图形，不是 QR 码、身份校验或密码功能。

用于正文、交互及焦点的色值独立校准，不直接将五个装饰色用作小字。

## 交互与页面

- 首页：五种形态可通过底部选择栏或下一形态按钮切换；渐进描线、印刷显影、轻微指针视差和缓慢漂移。支持暂停为完整静态画面，快速连续切换始终以最后选择为准。文章与片刻继续使用真实内容数据。
- 全站：沿用共用品牌 Logo，提供独立的内容标题、文章列表、片刻、映像、归档、实验室、聊天、浮层与表单样式。
- 登录：指纹构图、印刷式身份面板与专用接入动画。复用已有身份接口及跨路由连接状态，保留错误返回、跳过动画、慢导航恢复与焦点归还。
- Theme 页面：`/theme` 展示五套主题的大幅封面；异相封面复用首页 MD5 的同一原生 SVG，静态呈现。浅色、深色与系统模式即时生效，选择持久化并由首屏脚本恢复。全站与账号弹层的外观入口统一跳到此页，保留来源路径、查询参数与页内锚点供返回；当前标签页内的文章、聊天草稿在往返后恢复。
- 首页文案支持中文、英语、日语、德语；移动端保留共用导航、安全区与账号表单键盘避让。
- “减少动态效果”关闭描线、旋转、视差和过场等待；切到后台时跳过接入动画等待。

## 验证

新增 `tests/allotype-theme.test.mjs`，覆盖新旧图形算法的种子确定性与逐字节敏感性、五种形态切换、快速连续切换与暂停/继续、减少动画模式、主题持久化、键盘操作、1440/768/390/320px 明暗布局、四种语言、内容页面、移动菜单以及隔离的登录成功与失败场景。

```sh
node --test tests/allotype-theme.test.mjs
```

默认使用 `http://localhost:9999`，可通过 `TEST_BASE_URL` 指定其他实例。设置 `ALLOTYPE_SCREENSHOT_DIR` 可保存截图。测试拦截身份接口，不会向真实服务创建账号或提交登录。

项目需要 Node 20.9 以上；当前本机的一键启动配置使用已安装的 Node 24。
