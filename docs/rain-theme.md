# 雨声主题：视频观察与实现依据

## 来源与观察方法

- 参考：[【明石缪】翻唱歌曲「他人事の音がする / 声不关己」](https://www.bilibili.com/video/BV1qtMc6HEis)
- BVID：`BV1qtMc6HEis`；CID：`39639711829`；单 P，约 4 分 19 秒。
- 来源署名：词曲编曲 あめのむらくもP；演唱 明石缪；混音 ししおー；插画 ミツ蜂；影片 kkmfd。
- 2026-10-03 获取公开播放的 1280×720 视频。FFmpeg 解码扫描 7,752 帧（约 29.97 fps），记录每帧时间与场景变化分数。
- 人工查看全片 259 张一秒间隔时间轴画面；对 21.8s、48.8s、160.2s 起的三段转场分别提取连续 24 帧，检查切换方式；另提取高清关键帧查看纹理和构图。
- “逐帧扫描”指全片帧差计算；人工视觉判断来自时间轴、关键帧和上述连续帧，不声称人工逐一检查了全部 7,752 帧。
- 本地原片、帧分数、时间轴和连续帧图版保存在 `.git/ark-research/sound-theme/`，不作为应用依赖。

## 连续帧结论

- **21.8–22.6s**：文字雨幕连续滑动，约 22.1s 出现短暂白场，随后主体切换位置。适合学习分层运动，不复制频闪。
- **48.8–49.6s**：约 48.98s 硬切到纸白伞柱图；切后装饰与小字渐显，主体保持稳定。页面采用稳定主图和错峰出现。
- **160.2–161.0s**：短黑场、单帧高亮、夜景淡入，证明暗部不是简单反色，而是独立的深蓝水面情境。

## 设计方案

主题名称：**雨声 / Rain / 雨音 / Regen**。默认仍为原有 **档案 / Archive**。

- 视觉主题与浅色、深色、跟随系统分开选择。
- 延续 YororoIce 品牌与内容结构；新主题更轻、更疏朗，首页以青色伞幕、方片、雨线和水纹建立区别。
- 浅色：雾白底、深青正文、青灰辅助文字；装饰用高明度水青。
- 深色：蓝黑底、雾白正文、浅青交互色；水纹和雨幕为低对比背景。
- 正文、表单、菜单、弹窗与聊天共用语义颜色；大面积装饰限定在首页。
- 交互：主题选择即时生效、本地保存、跨标签页同步；刷新首屏恢复选择；保留旧 `ark.theme` 明暗偏好。
- 切换器提供当前选中状态、键盘操作、点击外部与 Escape 关闭；移动端不挤压导航。
- 动效采用 `ease-in-out`，不回弹；减少动态效果时关闭空间移动与循环动画。
- 应用图形使用 CSS / SVG 几何绘制，不将视频截图或人物插画作为网站资源。

## 实现位置

- 顶部导航的调色盘按钮打开「外观」面板；登录页及首次接入的账号弹窗也提供入口。
- `src/lib/appearance.ts`：视觉主题、明暗模式及首屏初始化脚本，保留旧 `ark.theme`，新增 `ark.design.v1`。
- `src/components/appearance/`：共享偏好存储与主题面板。浏览器禁止存储时，当前页面会话仍可切换；存储可用时支持刷新恢复和跨标签页同步。
- `src/styles/appearance.scss`：全局语义颜色；`_appearance-tokens.scss` 将颜色映射到原有组件变量。根布局在渲染前恢复偏好，不将整站改成客户端组件。
- `src/components/blog/rain-artwork.*`：三层伞形雨幕、细线空间、八角阵列、漂浮方片、水纹与竖排字。首页按根元素属性选择构图，原有档案轨道实现保留。
- 主题面板提供中、英、日、德四种语言；原生单选组支持方向键，弹层支持 Escape、外部点击和关闭后的焦点恢复。

## 两套主题的个性化 UI

在原有主题切换基础上，两套视觉语言延伸到各页面：

| 区域 | 档案 | 雨声 |
| --- | --- | --- |
| 导航与章节 | 编号导航、朱红选中线、大号章节序号 | 宋体导航、菱形选中点、居中篇章标题与缓慢水纹 |
| 首页内容 | 主篇与目录并列、深墨引言区 | 弧形主篇封面、横向三篇书目、留白引言区 |
| 文章列表 | 日期侧栏、索引线、紧凑横向条目 | 主篇加错落双栏、细边线书页；手机先显示标题摘要 |
| 片刻与归档 | 双栏编号片刻、年份索引 | 细线时间轴、错落片刻、轻量年份排版 |
| 阅读 | 强标题层次、朱红元信息边线 | 居中标题、舒适宋体行距、留白引用段落 |
| 聊天 | 直角通信侧栏、索引标识、硬朗输入区 | 圆润会话入口、信笺气泡、独立书写区 |
| 登录与外观 | 档案式身份面板、直角预览与控件 | 雨声印记、弧形身份面板、柔和表单与圆角控件 |

布局样式在 `src/components/blog/_theme-ui.scss` 中集中维护，通过 Sass mixin 编译进原有 CSS Module。`html[data-design]` 同时选择排版与颜色，内容组件和输入状态保持挂载；切换主题不会清空聊天草稿。原共享布局保留于 `blog.module.scss`，个性化前的实现可见提交 `a8f0b7c`。

章节水纹和登录印记为独立 SVG 几何图形，不请求新图片或视频资源。所有新增动画使用 `ease-in-out`，减少动态效果时停用。
