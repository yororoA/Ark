# 雨声登录过渡：伞阵显现 → 落纸揭幕

参考 B 站 `BV1qtMc6HEis`。范围从约 **1:03.567** 的第一批白色俯视伞面，
到约 **1:07.133** 的大纸片落下结束。不绘制人物，不接续后面的青色街道分镜。

## 观察与实现

本地逐帧观察 63–65 秒的 60 帧，以及 65–67.133 秒的连续画面，
用于判断动作顺序、比例和时间。产品代码只包含独立几何与运动公式。

| 参考时间 | 观察 | 程序化实现 |
| --- | --- | --- |
| 63.567 起 | 俯视伞面先闪白，再变青；约每 0.43 秒增加一批 | 直边八角伞面、浅色径向伞骨，四组错时显现与局部亮度脉冲 |
| 65.267–65.333 | 模糊倒置伞从底部快速升入 | 折面伞顶、向上位移、近景失焦；入场提前一帧起步，白场前伞面完整露出 |
| 65.367 | 白场切换 | 一次纸白底过场 |
| 65.400–66.567 | 倒置伞、上方纸片、汇聚的落纸、两侧断笔水纹 | 大、中、小三级方纸、稳定的铅笔描边、连续翻转和下落、带断口和收笔的曲线 |
| 66.600–66.933 | 大纸片快速压下，后景缓慢下沉，各层失焦 | 前后景独立位移与模糊；伞和落纸共享后景下移，幕纸更快越过，完全遮挡后交接路由 |
| 66.933–67.133 附近 | 大纸片继续落下，显出下一场景 | 纸张向下倾斜移出，透明画布逐步露出真实目标页 |

网站标题使用“把片刻，留给雨声。”。色彩取自雨声主题令牌，适配浅色和深色。
竖屏按视口重新布置伞阵、纸片与水纹，并减少对象数量。

正常播放约 **3.734 秒**：从首闪到整张纸遮挡为 3367ms，目标页揭幕为 367ms。
最后的揭幕比参考片段稍长，供真实页面交接使用。等待认证或路由的时间另计。
这是一套几何复刻，不宣称与原片逐像素一致。

## 页面交接

动画绘制层位于根布局的 Portal，登录页卸载不重启动画。
认证成功且幕纸完全遮挡后调用 `router.replace(destination)`。
认证或目标路由未就绪时，保持幕纸覆盖全部四角，底层页面为 `inert`。
目标路由提交后，画布清除背景，只绘制下落的幕纸；纸张外面是透明区域。
正常播放全程不降低绘制层透明度，不在片尾再做整屏淡出。

## 纸片与景深细化

依据用户补充的五张截图，统一了首页与登录动画的伞形，并细化：

- 近景大倒伞在伞阵铺满后从下向上出现；伞面与伞柄分层，
  保持伞柄可辨，伞面明显失焦。1280×720 下近景伞面模糊半径为 18px。
- 纸片采用大、中、小三级尺寸，大纸不再随着汇聚缩成碎屑；
  描边颜色取自 `--ark-muted`，边缘有轻微偏移、笔压变化和局部复笔。
  这些变化由每张纸的固定种子生成，随纸张运动，不逐帧跳动。
- 顶部文字穿插在两批纸片之间，按“后层纸片 → 文字 → 前层纸片”绘制，
  因而同时存在文字盖住纸片、纸片遮住文字的关系。每张纸的前后层级由固定
  对象种子决定，在下落、翻转和视口调整时保持一致。
- 幕纸扫落期间，倒伞、落纸、文字和水纹共享缓慢下移，
  最大位移为视口高度的 9%；前景幕纸在同一时间段跨越超过一个视口。
- 模糊交给两个独立 Canvas 层的 CSS filter，避免对每张纸单独执行滤镜。
  1280×720 下收尾后景最大模糊为 3.24px，前景幕纸为 5.76px。
  画布 DPR 上限为 1.5；竖屏减少纸片和水纹数量。
- 遮挡底色保持到揭幕开始，避免模糊边缘透出登录页；调整视口后同步重绘，
  避免 Canvas 清空时出现一帧空白。

## 回退与键盘操作

- 登录、注册、游客和账号切换使用启动时选定的主题。
- `returnTo` 只接受站内非登录地址。
- 失败显示可操作的错误与返回入口。
- pending 时返回 / Escape 取消；迟到响应不恢复过渡。
- success 时跳过 / Escape 仍等待目标页，随后执行简短静态淡出。
- 减少动态效果、Canvas 不可用或上下文丢失：静态伞与 200ms 淡出。
- 路由等待超过 12 秒时显示目标页直达链接和返回按钮。
- Tab 焦点限制在过渡控件；结束后移除 `inert`、恢复滚动，并聚焦目标页 `main`。

  绘制层 opacity 仍为 1，底层 pathname 已为目标页，登录布局已卸载。
- TypeScript、修改文件 ESLint、隔离生产构建和 `git diff --check` 通过。

视觉检查基于分镜、关键构图与实际播放截图；没有使用原片轮廓或像素相似度评分。
