# 雨声登录过渡

## 视觉与时序

终端（`archive`）继续使用原有 `ConnectionSequence`，其分镜和时长不变。
雨声（`rain`）使用独立的三维伞面，参考 `BV1qtMc6HEis` 的水青伞幕、
纸白空间、八角轮廓与细线关系。伞面、伞骨、伞轴和弯柄由几何体构造，
不使用参考视频画面或音频资源。

| 阶段 | 时长 | 行为 |
| --- | --- | --- |
| 仰视与攀升 | 4.4s | 从伞柄下方向伞面仰视，围绕伞轴旋转约 297°，上升至俯视 |
| 伞面遮挡 | 0.75s | 镜头向伞面推进，八片伞布覆盖视口四角 |
| 页面交接 | 按实际加载时间 | 认证成功后切换目标路由；伞保持打开，等待非登录页提交 |
| 收伞 | 1.35s | 伞骨向伞轴折叠，滑套下移，布面聚拢，逐步露出目标页 |
| 离场 | 0.24s | 收起的伞淡出，恢复目标页交互与焦点 |

视角与折叠采用平滑 S 曲线，无弹簧或缩放回弹。深色模式使用青灰伞面和蓝黑背景。

## 生命周期

- `rain-connection-store.ts` 只保存一次过渡的状态、目标地址和回退回调，不持久化、不保存密码。
- `RainConnectionBoundary` 位于根布局，在 `/login` 卸载后仍保留动画实例；路由内容在过渡期间为 `inert`。
- `rain-connection-sequence.tsx` 负责时序、认证状态、焦点、跳过、失败回退和渲染器降级。
- `rain-umbrella-scene.ts` 负责相机、几何体和材质；逐帧数据不经 React 状态传递；卸载时释放几何体、材质、渲染器与观察器。
- 登录、注册、游客接入、已有账号切换均以启动时的主题选择对应动画。
- `returnTo` 仅允许站内地址，指向登录页或根路径时使用 `/home`，避免收伞后仍露出登录页。

## 等待与降级

- 请求失败：停止行进，显示接口错误，并提供返回登录。
- 认证尚未完成：保持伞面；返回或 Escape 可撤销本次视觉过渡，迟到响应不会重启它。
- 认证成功后跳过：仍等目标页提交，再执行短淡出。
- 减少动态效果：不加载 Three.js 伞模型，静态伞形配合 200ms 淡出。
- WebGL 不可用或上下文丢失：切换到同一静态过渡，登录功能保持可用。
- 路由等待超过 12s：提供直接打开目标页和返回入口。
- 标签页切到后台时不会在恢复后瞬间跳完空间动画。

## 验证方式

在隔离的本地后端中执行真实表单、路由和键盘操作。按时间戳采样仰视、
攀升、俯视、遮挡、折叠、页面揭示；在收伞期间断言目标路由已提交且登录页已卸载。
另外检查失败重试、慢路由、取消后的迟到响应、320px / 390px、深色模式、
减少动态效果、WebGL 回退和终端动画回归。
