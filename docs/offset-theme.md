# 错版 / OFFSET

第八套外观，主题标识 `offset`，在 `/theme` 选择「错版」。以朱红 `#ef3d2f`、米白 `#eee9dd`、墨黑 `#191817` 为基础，使用实验排字、套色偏移、定位十字和印版切屏。支持明、暗、系统模式与中英日德文案。

主题装饰全部由 HTML 排字、CSS 图形和浏览器动画构成，没有天空照片或其他新增位图素材。文章封面和图库继续使用已有内容图片。

## 页面

- 首页以 `OFF / SET.` 双行字版开场，文字从裁切区移入并保留红黑套色偏差。文章、片刻、活动日历与代码活动沿用真实数据；主文章、短篇列表、编号片刻和页尾 `ARK` 排字组成阅读路径。没有构图播放器或自动轮播。
- 目录使用五层交错横版与逐行排字入场，定位标记跟随鼠标或键盘焦点。入场中关闭会读取当前画面并反向退场；支持方向键、Home/End、Tab 焦点约束、Escape 关闭及焦点返回。
- 文章、阅读、片刻、图库、归档、关于、实验室、聊天和表单统一使用硬边框、编号、墨黑分隔线及朱红强调。手机布局改为单列，正文内容与原有业务保持一致。

## 登录：套准、套印、进入

海报采用红黑错位的 `OFF / SET` 字版。提交后呈现真实认证状态：等待时只有定位十字小幅移动，可以返回取消；失败时展示错误并保留返回入口。装饰动画不产生认证成功。

真实认证成功后开始有限分镜，时间从主动作启动算起：

1. 0–650ms：五条文字切片以 45ms 间隔交错套准，红色底版回收。
2. 780–1180ms：实际用户名的朱红套印层逐步揭示。
3. 1080–1540ms：三块不等宽竖向印版从上下合拢；完全覆盖后才调用导航。
4. 目标路由提交、真实主内容稳定并产生 `pageReady` 后，三版上下交错抽离，600ms 后释放页面。

主动作共约 2.14 秒，不含认证和目标页加载时间；首次出现另有最多 250ms 的定位准备。成功后可跳过装饰等待，仍遵守实际页面就绪条件。导航超过 12 秒会提供直接打开目标页和返回重试。取消后忽略迟到认证结果，重复点击不重复认证；结束时恢复页面交互并将焦点交给主内容。

实现位于 `offset-connection.tsx` 和对应样式。观察 `data-status`、`data-phase`、`data-page-ready`、`data-navigation-slow`；五条字版为 `data-offset-login-type-slice`，姓名套印为 `data-offset-login-name`，三版为 `data-offset-login-exit-sheet`。

## 全站切屏：覆盖、导航、就绪、揭幕

`offset-effects.tsx` 接管主动请求切屏的站内跨页面链接。三块横向印版错拍覆盖全屏（510ms 动作，加 74ms 间隔）；完整覆盖后执行一次导航。目标路径必须已经变更、加载边界消失，且真实主内容稳定 90ms，才进入揭幕；三版反向交错移出（590ms 动作，加 74ms 间隔）。经过固定时间不等于页面就绪。

普通锚点、同页筛选、外链和修饰键打开链接维持原有行为。切屏可通过按钮或 Escape 跳过；6.5 秒未就绪显示直接打开入口，20 秒仍未就绪执行原链接回退。结束后焦点进入目标主内容；取消导航时返回原触发位置。

## 动态偏好与兼容

`prefers-reduced-motion` 下首页直接展示排版、目录直接打开、站内链接使用即时导航；登录跳过装饰阶段，同时保留真实认证和目标页面就绪检查。标签页隐藏时也简化正在进行的动作。没有持续运行的 JavaScript 绘制循环；认证等待仅保留定位十字的 CSS 微动。

外观继续保存到 `localStorage['ark.design.v1']`，明暗模式沿用 `ark.theme`。首屏脚本及 `parseDesign` 会将旧值 `sky` 读取为 `offset`，刷新与跨标签页同步都应用新主题；重新选择主题时保存规范的 `offset` 值。无需清除原有账号、草稿或聊天数据。
