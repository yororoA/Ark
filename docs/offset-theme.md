# 错版 / OFFSET

第八套外观，主题标识 `offset`，在 `/theme` 选择「错版」。以朱红 `#ef3d2f`、米白 `#eee9dd`、墨黑 `#191817` 为基础，加入蓝色 `#3563e9` 与浅蓝 `#dae8f9` 的几何构成，使用实验排字、套色偏移、固定信息边框和印版切屏。深色模式的蓝色改为 `#9bbaff`，底色为 `#202f4a`。支持明、暗、系统模式与中英日德文案。

主题装饰全部由 HTML 排字、CSS 图形和浏览器动画构成，没有天空照片或其他新增位图素材。文章封面和图库继续使用已有内容图片。

## 页面

- 首页以固定的刊头、边框和底栏组织 `OFF / SET.` 双行字版、阅读入口和两幅文字构成。蓝色方框从聚集到展开，中央 `a ↗`、实心方块与空心框共用方形母题；一次入场后停止，悬停时仅有轻微展开。另一幅横读为 NOTES、FRAGMENTS、REFLECTIONS、IMPRESSIONS、DETAILS、STORIES，强调字母沿共同轴线纵读为 OFFSET。手机端两幅构成改为上下排列。文章、片刻、活动日历与代码活动继续沿用真实数据，没有构图播放器或自动轮播。
- 目录使用五层交错横版与逐行排字入场，定位标记跟随鼠标或键盘焦点；固定蓝色框内的九个方块随当前目录项错位聚散。入场中关闭会读取当前画面并反向退场；支持方向键、Home/End、Tab 焦点约束、Escape 关闭及焦点返回。
- 文章、阅读、片刻、图库、归档、关于、实验室、聊天和表单统一使用硬边框、编号、墨黑分隔线及朱红强调。手机布局改为单列，正文内容与原有业务保持一致。

首页上下两块字版相差两格，`OFF` 落在墨色版上，`SET.` 落在朱红版上。每格随视口在 12–38px 之间变化。同一格距也用于栏目编号与标题、内容页标题与英文副题。首页片刻卡在宽屏逐张降低起点，日期收在共同底线，手机改为左右交替缩进。

文章精选根据内容排版。宽屏有封面和多篇文章时，先给目录标题和底部操作留足空间，封面在限定高度内伸缩。右栏根据实际剩余高度，把「NO SMALL THINGS.」排成三行或收成一行。761–1000px 时，有图主稿改为左图右文，目录移到下方。无封面时主稿横跨全栏；只有一篇时省去目录。760px 及以下按阅读顺序上下排列。

## 登录：展开、套印、开窗

海报采用固定的信息边栏、蓝色嵌套方框与红黑错位的 `OFF / SET` 字版；中心编号 08 居中，周围图块错拍展开。提交后呈现真实认证状态：等待时只有定位十字小幅移动，可以返回取消；失败时展示错误并保留返回入口。装饰动画不产生认证成功。

真实认证成功后开始有限分镜，时间从主动作启动算起：

1. 0–1040ms：蓝色嵌套框从小框展开，图块散开，`OFF / SET` 字版放大；五条切片从 380ms 起以 45ms 间隔套准，红色底版回收。
2. 1040–1460ms：实际用户名的朱红套印层揭示；方框与字版在 1560ms 前完成重排。
3. 1580–2060ms：蓝色矩形从局部旋转扩展至全屏，呈现嵌套框和 `IN ↗`。仅覆盖层自身的 `animationend` 可以释放导航，子动画完成或单纯经过时间均不算覆盖完成。
4. 目标路由提交、真实主内容稳定并产生 `pageReady` 后，上、右、下、左四片向外抽离，中央窗口扩大，嵌套框同步放大穿出；动作 700ms，720ms 后释放页面。

主动作共约 2.78 秒，不含认证和目标页加载时间；首次出现另有最多 160ms 的定位准备。成功后可跳过装饰等待，仍遵守实际页面就绪条件。导航超过 12 秒会提供直接打开目标页和返回重试。取消后忽略迟到认证结果，重复点击不重复认证；结束时恢复页面交互并将焦点交给主内容。

实现位于 `offset-connection.tsx` 和对应样式。观察 `data-status`、`data-phase`、`data-page-ready`、`data-navigation-slow`；五条字版为 `data-offset-login-type-slice`，姓名套印为 `data-offset-login-name`，覆盖层为 `data-offset-login-sheets`，四片为带 `data-side` 的 `data-offset-login-exit-sheet`。

## 全站切屏：覆盖、导航、就绪、揭幕

`offset-effects.tsx` 接管主动请求切屏的站内跨页面链接，分为三段：

1. 0–850ms：定位框从点击位置移向中央；蓝、米白、朱红三片斜边色版从左右拼合，分别在 120/175/230ms 开始，持续 620ms。`NEXT` 字母错拍归位，目的地文字在固定信息框内显现。三片全部完成后才执行一次导航。
2. 完整覆盖并等待：目标路径必须已经变更、加载边界消失，且真实主内容稳定 90ms，才进入揭幕。经过固定时间不等于页面就绪。
3. 720ms 揭幕：三片色版保持原位，父层 `data-offset-shutter` 的 `clip-path` 从中央开窗直至窗口超过视口；文字场景放大淡出，三层边框同步穿出。窗口打开完成后才清理过场。

普通锚点、同页筛选、外链和修饰键打开链接维持原有行为。按钮或 Escape 跳过动画仍保留真实导航；浏览器返回会清理当前过场。交接前重复请求采用最新目标，交接后不重复导航。6.5 秒未就绪显示直接打开入口，20 秒仍未就绪执行原链接回退。结束后焦点进入目标主内容；取消导航时返回原触发位置。

## 动态偏好与兼容

`prefers-reduced-motion` 下首页直接展示排版、目录直接打开、站内链接使用即时导航；登录跳过装饰阶段，同时保留真实认证和目标页面就绪检查。标签页隐藏时也简化正在进行的动作。没有持续运行的 JavaScript 绘制循环；认证等待仅保留定位十字的 CSS 微动。

外观继续保存到 `localStorage['ark.design.v1']`，明暗模式沿用 `ark.theme`。首屏脚本及 `parseDesign` 会将旧值 `sky` 读取为 `offset`，刷新与跨标签页同步都应用新主题；重新选择主题时保存规范的 `offset` 值。无需清除原有账号、草稿或聊天数据。
